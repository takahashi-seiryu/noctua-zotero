Note guide

The editor opens in a white light theme by default. Use Light / Dark at the top right to change the plugin theme for all open notes. Settings opens Noctua Notes preferences, where System follows your operating system appearance.

Click rendered text to edit its LaTeX source beside a live preview. Press Escape or Cmd/Ctrl+Enter to finish. Select text without entering the editor.

Use the insertion controls between blocks to add text or a drawing at that position. Cmd/Ctrl+Shift+D inserts a drawing after the focused block. A text block following a drawing can appear beside it or below it.

In LaTeX source, parentheses, brackets, braces and dollar signs pair automatically. Type a closing character to step over it. Select text and type an opener to wrap it; Cmd/Ctrl+B and Cmd/Ctrl+I toggle bold and italic.

Write $inline math$, $$display math$$, \section{Headings}, \label{key}, and \ref{key}. Shared \newcommand definitions belong in the preamble. Use Insert citation to choose a Zotero library item. Citations resolve to author and year, link to the item, and generate a reference list.

Undo and Redo restore text, title, preamble, blocks, and drawings during this editor session. History is bounded and is cleared when reloading the saved version. Drawings retain vector strokes; paste or drop raster images to add image blocks.

Changes save automatically; the status at the top shows progress and any conflict or error. Zotero handles file sync. Cmd/Ctrl+S flushes pending changes immediately. Use Zotero’s Tools menu or an item’s right-click menu to import source into a separate editor or export a portable backup of the current note. Resolve conflicts by exporting your draft from the menu and reloading the saved version.
